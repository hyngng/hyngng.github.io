Lors du développement d'un [programme de trading automatique d'actions](https://hyngng.github.io/posts/astp-devlog/), je me suis retrouvé dans l'impossibilité d'exécuter le programme dans un environnement 64 bits. En cherchant des alternatives pour configurer un environnement virtuel 32 bits, la plupart des gens recommandaient Anaconda, mais c'était un peu fastidieux. En cherchant une autre solution, j'ai trouvé un moyen d'ouvrir un environnement virtuel 32 bits dans VS Code. En suivant la procédure pas à pas, la méthode s'est avérée assez simple, je l'ai donc résumée ici.

## **Installation de l'environnement virtuel**

```sh
python -m venv nom_fichier

cd Scripts
.\Activate.ps1

deactive
```

Il suffit d'entrer ces trois commandes pour créer le fichier à l'emplacement souhaité. L'environnement virtuel peut être exécuté en appelant le fichier `Scripts/Activate.ps1`, et désactivé avec la commande `deactive`. Si `(venv)` apparaît devant le chemin du fichier dans la console VS Code, l'environnement virtuel est actif.

## **Résolution d'erreur**

```sh
C:\Users\UserNameHere\AppData\Local\Programs\Python\Python311-32\python.exe -m venv venv32bit
```

Si l'environnement virtuel 32 bits ne s'ouvre pas malgré la procédure ci-dessus, installez [Python 32 bits](https://www.python.org/downlostart_with_ads/windows/) puis appelez directement `python.exe` 32 bits dans la console.

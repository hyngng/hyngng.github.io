При разработке [программы для автоматической торговли акциями](https://hyngng.github.io/posts/astp-devlog/) возникла ситуация, когда программу нельзя было запустить в 64-битной среде. Я поискал способы создать 32-битную виртуальную среду; в большинстве случаев рекомендовали Anaconda, но это было хлопотно. В итоге я нашёл способ открыть 32-битную виртуальную среду в VS Code. Метод оказался несложным, так что я кратко его описал.

## **Установка виртуальной среды**

```sh
python -m venv имя_файла

cd Scripts
.\Activate.ps1

deactive
```

Достаточно ввести три команды, и файл будет создан по нужному адресу. Виртуальную среду можно запустить, вызвав файл `Scripts/Activate.ps1`, и выйти из неё командой `deactive`. Если перед путём к файлу в консоли VS Code отображается `(venv)`, виртуальная среда работает.

## **Решение ошибок**

```sh
C:\Users\UserNameHere\AppData\Local\Programs\Python\Python311-32\python.exe -m venv venv32bit
```

Если 32-битная виртуальная среда не открывается после выполнения вышеуказанных действий, можно установить [32-битную версию Python](https://www.python.org/downlostart_with_ads/windows/) и напрямую вызвать 32-битный `python.exe` в консоли.

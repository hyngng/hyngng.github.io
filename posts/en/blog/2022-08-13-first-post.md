## **After Two Days of Struggle**

I've launched my GitHub blog! I initially considered Tistory or Velog, but I was intrigued by the ability to directly tweak the blog theme code in detail, so I chose GitHub blog. I ran into more hurdles than expected — a `layout: home # index page` error, a missing `gh-pages` branch, issues with the `pages-deploy.yml` file — and was flustered, but seeing the blog page finally render properly feels rewarding.

GitHub blogs seem to be primarily used by developers to record what they've studied or newly learned. Personally, I'd like this space to center on everyday life while still subtly showcasing who I am. It'd be great if it serves as both a personal record and a way to present myself to others. I plan to cover topics stemming from what I study, experience, and think about, while keeping the post categories diverse.

Hope this blog grows rich with content over time. For now, I'll focus on customizing it to my taste. 😚

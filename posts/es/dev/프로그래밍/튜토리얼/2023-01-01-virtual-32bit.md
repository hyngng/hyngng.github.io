Mientras desarrollaba un [programa de trading automatizado de acciones](https://hyngng.github.io/es/dev/astp-devlog/), me encontré con que no podía ejecutar el programa en un entorno de 64 bits. Busqué alternativas para crear un entorno virtual de 32 bits y la mayoría recomendaba Anaconda, pero me pareció un poco tedioso. Buscando otras opciones, encontré una forma de abrir un entorno virtual de 32 bits en VS Code. Siguiendo los pasos con calma, vi que no era difícil, así que lo resumí brevemente.

## **Instalación del entorno virtual**

```sh
python -m venv nombre_archivo

cd Scripts
.\Activate.ps1

deactivate
```

Con solo introducir estos tres comandos se crea un archivo en la ruta deseada. El entorno virtual se puede activar invocando `Scripts/Activate.ps1` y se desactiva con el comando `deactivate`. Si aparece `(venv)` antes de la ruta del archivo en la consola de VS Code, significa que el entorno virtual se está ejecutando correctamente.

## **Solución de errores**

```sh
C:\Users\UserNameHere\AppData\Local\Programs\Python\Python311-32\python.exe -m venv venv32bit
```

Si aun así no se abre un entorno virtual de 32 bits, instalando [Python de 32 bits](https://www.python.org/downloads/windows/) e invocando directamente `python.exe` de 32 bits desde la consola se soluciona el problema.

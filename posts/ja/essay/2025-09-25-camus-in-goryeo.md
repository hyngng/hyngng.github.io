## **アルベール・カミュの不条理哲学**

20世紀フランスを代表する作家であり実存主義の思想家であるアルベール・カミュは、「人生に生きる価値はあるのか」という根源的な問いからその哲学を始める。彼が見出したのは、意味を探求する人間の熱望と、それに対して沈黙する非合理な世界との間の、避けがたい対立である。根本的に不安定な関係のなかで、人間は明晰な認識のためにある事実を受け入れ、ある事実をあえて無視する。こうした心理作用は本能的で自然なものだが、いつか無視してきたものと向き合うとき、大きな混乱と衝撃を経験する——これが不条理である。

不条理は人生の意味を提示するために考案された概念だが、人間の熱望と世界の沈黙との対立は結局のところ認識的衝撃に帰着するという点が見て取れ、そのおかげで思いのほか多様な状況において不条理を連想することができる。アルベール・カミュが挙げた例を引くなら、人間理性の精髄として「信じるべきもの」とされる科学でさえ、実はいつでも覆されうる最も合理的な仮説の集合体にすぎないと気づいたとき、不条理に映りうる。

彼の哲学によれば、不条理に直面した人間が選べる対応は、否定、回避、対面の三つの形で現れる。不条理を否定したり回避したりするのは逃避的な態度で現実に順応することであり、カミュはこれをより直截的に、宗教への帰依や肉体的自殺として説明する。一方、対面とは不条理を人生の一部として認めながらも運命に屈せず立ち向かう反抗的態度であり、これこそがカミュが望ましいと考える生き方である。

## **伝統的な高麗-女真の関係**

唐は世界史でも類を見ないタイプの帝国であった。強盛な軍事力で勢力を大きく広げただけでなく、三省六部制、律令のような統治体制、そして儒・仏・道教の三教に代表される国家理念まで、唐の主要文物を周辺に伝播させ、東アジア文化のヘゲモニーを占めた。高麗の国家的、民族的自負心は、基本的に中世東アジアの多極体制と海東天下観、仏国土思想からも生まれていたが、中国の先進文物をうまく輸入して独自に発展させたという文化的達成感にも根ざしていた。

一方、高麗にとって女真は軽蔑の対象であった。女真は靺鞨に由来する民族で、すでに高句麗において韓民族の影響下に置かれた過去を持つ種族であっただけでなく、当代の高麗の観点から文化的象徴性を見出しがたい蛮人だった。女真の代表の呼称は酋長であり、高麗の立場からは自らを[朝貢し](https://db.history.go.kr/goryeo/level.do?levelId=kr_004r_0100_0060_0040&types=r)、[帰附し](https://db.history.go.kr/id/kr_009r_0020_0020_0040)、[貢物を捧げに来る](https://db.history.go.kr/goryeo/level.do?levelId=kr_004r_0050_0010_0010&types=r)一段下の対象であった。一例として、高麗を建国した王建は女真に向かって「北蕃の人面獣心」という[罵倒](https://db.history.go.kr/goryeo/level.do?levelId=kr_002r_0010_0040_0020&types=r)さえ辞さなかった。このヒエラルキー認識は女真自身も大きくは変わらず、高麗を高句麗、渤海に関連する上位文明として認め、自らを高麗の蕃と表現する外交上の修辞を用いた。

この関係は約200年間続いた。渤海の滅亡後、女真は遼の一員として服属しながらも高麗を「父母の国」と呼び、国境貿易を通じて生活必需品を調達されたり、高麗に帰化して官職を得たりするなど、高麗の文明圏の下で保護と統制を受ける辺境の存在にとどまっていた。高麗もまた、そうした女真との非対称関係を国境の安定化を図る手段として、また国内における海東天下観の正当性を達成する思想的根拠として利用した。

## **金の建国と高麗の動揺**

12世紀初頭、高麗仁宗の治世は高麗史において注意深く見るべき時期である。彼が君主であったとき、国内外を問わず権力の対立が多様な形で出現しており、それに伴って政治地形が急速に変化していた。宋の冊封提案と賈島の要請、黄州瞻の称帝建元の要請といった小さな事件を除き、当時の高麗内外で起きた主要な情勢変化を時系列にまとめると次のようになる。

| 年 | 主要事件 |
| :--- | :--- |
| 1109年 | 高麗の女真征伐が失敗に終わる。 |
| 1115年 | 女真から金が建国される。 |
| 1116年 | 高麗が遼の年号の使用を中止する。 |
| 1122年 | 高麗仁宗が即位する。 |
| 1125年 | 遼が北宋と金によって滅亡する。 |
| 1126年 | 高麗が金に称臣する。 |
| 1126年 | 高麗で李資謙の乱が起こる。 |
| 1127年 | 北宋が金に滅亡する。 |
| 1135年 | 高麗で妙清の乱が起こる。 |
| 1142年 | 高麗が金の年号の使用を開始する。 |

彼の治世が高麗全盛期の延長線上にあったことを考えれば、金に対する事大は、長らく自らに帰附してきた蛮族への称臣であるという点で大きな認識の変更を要する難しい決断であり、高麗内部の立場も、我々も帝国を宣言し金の征伐を準備すべきだとする西京門閥貴族の主張と、いま我が国の国力が思わしくなく、いま金が強大だから我々が金に称臣すべきだとする開京門閥貴族の主張に分かれた。

どの立場が政治的に正しかったかは別として、1126年当時、実権を握っていた李資謙が[金に対する恣意的な称臣](https://db.history.go.kr/id/kr_015r_0060_0030_0030)を決定し、仁宗がこれを受け入れて[皇帝に向けた表文が送られた](https://db.history.go.kr/goryeo/level.do?levelId=kr_015r_0060_0040_0020&types=r)。まもなく李資謙は追放されるが、外交路線は修正されず、蛮族と無視してきた女真に対する事大であるという点で15年という長い時間を要したが、ついに1142年、高麗王が金に冊封され、高麗は正式に[金の年号を使用](https://db.history.go.kr/id/kr_017r_0040_0070_0010)し始める。

この突然の政治的流れは高麗の海東天下観を脅かし、それに伴って政治的矛盾を惹起し、西京遷都運動を経て[妙清の乱](https://db.history.go.kr/goryeo/level.do?levelId=kr_016r_0070_0010_0020&types=r)という極端な形での反発に至った。ただし妙清の乱は単に伝統と自主性を守ろうとする動きだけではなく、その意義を理解するには複雑な政治的地形をまず見ておく必要がある。1127年、政治的大物拓俊京を流配する過程で、その空白を鄭知常を求心力とする西京の政治勢力が引き継ぐことになり、仁宗もまた金富軾に代表される伝統的な開京門閥貴族を牽制する意図から彼らを優遇した。

こうした状況のなかで、西京派が西京遷都と称帝建元など現状打破を通じた急進的進取主義路線を提示したことで、現状維持を通じた実利的現実主義の立場を堅持していた開京派との対立が始まった。単なる政治路線の違いを超え、西京派は風水地理と仏教的神秘主義を、開京派は合理主義的儒教思想を前面に押し出し、この状況は両政治勢力の利権争いであり、国風派と漢学派の理念対立、仏教と儒教の対立の様相にまで発展する。

この緊張状況は、西京派の名のもと計画されていなかった反乱が起き、[鎮圧されることで](https://db.history.go.kr/goryeo/level.do?levelId=kr_016r_0080_0020_0030&types=r)、終結した。結果的に高麗のヘゲモニーは開京の政治勢力が掌握することになり、権力均衡は崩れ、西京の地位も低下した。今日よく知られる実利的事大主義と儒教的保守主義、三韓継承意識のような思想は、このとき競争相手の消滅を機に強固になったか、少なくとも礎が据えられたのである。

## **二つの思想に対する個人的評価**

12世紀の高麗が直面した状況は、過去の高句麗の栄光を継承した自主国家としての尊厳と自負心を守りたいという人間的な熱望と、かつて蛮族と見なしていた女真族がその信念を嘲笑うかのように打ち立てた強大な金、そしてこうした現実から発生した内部的政治矛盾のすべてを示しているという点で、国家レベルの巨大な不条理であった。カミュの観点を借りるなら、この状況をめぐって当時の高麗の主流政治勢力であった西京派と開京派の分かれた対応は、次のように異なって理解できるかもしれない。

西京派の主張は金の征伐に帰結するという点で、世界の沈黙に対する否定や反抗と見る余地もあるが、大衆と王を説得するために用いた公式の論理は仏教や風水など神秘主義に基づく希望であり、彼らの運動はその信念なしには成立し得なかったという点で、哲学的自殺に近い。特に西京に遷都して宮闕を建てればすべての問題が解決するという信念は、感情的には痛快かもしれないが、不条理を理性で認識しそのなかで戦う代わりに、別の非合理で不条理を覆い隠そうとする試みであった。

一方、開京派の主張は、金の征伐という感情的訴えや盲目的信念に依存する代わりに、屈辱的な現実を国家存続のための人生の条件として受け入れ、外交的緊張関係の解消といった実利を追求する形をとっている。これは不条理を否定したり逃避したりする代わりに、それを人間の条件として抱擁する態度であり、不条理と対面しながら自らの道を歩むという点で反抗的人間の姿に近い。それは明らかに哲学的省察以前に既得権益維持のための手段であったが、500年後の丙子胡乱で同様のジレンマが再現されたとき、斥和派の強硬傾向が主流となった結果がどうであったかを考えれば、開京派の提示した要点は、不条理に立ち向かうための人間の唯一の武器である理性をつかもうとする試みの一環として理解しても、大きな違和感はないように思う。

個人的には、歴史に「もし」はないので、どちらの主張が正しかったかについては言葉を控えたい。ただし、一連の事件があった直後の1170年、毅宗の時代に武臣政変が起きているため、もし国家運営の哲学が正常に維持されていたなら、高麗が金に対してどのような外交路線をとっただろうか、内部的にどのような議論が交わされただろうかについて知る可能性は失われており、それが惜しまれる。

[株式自動売買プログラム](https://hyngng.github.io/posts/astp-devlog/)を開発中、プログラムを64bit環境で実行できなくなったことがありました。代替として32ビット仮想環境を構築する方法を探してみると、ほとんどがAnacondaを推奨していましたが、少し面倒だったので代替案を探してみたところ、VS Codeで32ビット仮想環境を開く方法がありました。ゆっくり試してみると方法が難しくなかったので簡単にまとめました。

## **仮想環境のインストール**

```sh
python -m venv ファイル名

cd Scripts
.\Activate.ps1

deactive
```

三つのコマンド入力で希望のアドレスにファイルを作れば完了です。仮想環境は`Scripts/Activate.ps1`ファイルを呼び出して実行でき、`deactive`コマンドを入力して終了できます。VS Codeコンソール画面のファイルパスの前に`(venv)`が表示されていれば、仮想環境が正常に実行されている状態です。

## **エラー解決**

```sh
C:\Users\UserNameHere\AppData\Local\Programs\Python\Python311-32\python.exe -m venv venv32bit
```

上記のように進めても32bit仮想環境が開かない場合、[32ビットPython](https://www.python.org/downlostart_with_ads/windows/)をインストールした後、コンソール画面で32ビットの`python.exe`を直接呼び出すと解決します。

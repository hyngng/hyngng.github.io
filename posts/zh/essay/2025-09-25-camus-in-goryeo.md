## **阿尔贝·加缪的荒谬哲学**

作为20世纪法国代表作家和存在主义思想家的阿尔贝·加缪，其哲学始于"生命是否值得活"这一根本性问题。他发现的是：人类寻求意义的渴望与对此保持沉默的非理性世界之间无法避免的对立。在这种根本上不稳定的关系中，人类为了清晰的认知观，接受某些事实而刻意回避另一些事实。这种心理作用是本能的、自然的，但当直面曾经回避的事物时，会经历巨大的混乱和冲击——这就是荒谬。

虽然荒谬是为提出生命意义而构想的概念，但可以发现人类的渴望与世界的沉默之间的对立最终以认知冲击告终，因此荒谬可以在比想象中更多的情况下被联想到。引用阿尔贝·加缪所举的例子，即使是作为人类理性精华、是"必须相信"的科学，当意识到它实际上只是随时可能被推翻的最合理假说的集合体时，也会显得荒谬。

根据他的哲学，面对荒谬的人类可以选择三种应对方式：否定、回避和直面。否定或回避荒谬是一种逃避现实的态度，加缪更直白地将其解释为皈依宗教或肉体自杀。相反，直面是承认荒谬为生活的一部分，同时不屈服于命运而与之对抗的反抗态度——这才是加缪认为理想的生活方式。

## **传统的高丽-女真关系**

唐朝是世界史上罕见的帝国类型。它不仅以强大的军事力量大幅扩张势力，还通过三省六部制、律令等统治体制，以及儒、佛、道三教为代表的国家理念，将唐朝的主要文物传播到周边，占据了东亚文化的主导权。高丽的国家和民族自豪感虽源于中世纪东亚的多极体制、海东天下观和佛国思想，但也根植于成功引进中国先进文物并独立发展的文化成就感。

另一方面，对于高丽而言，女真是蔑视的对象。女真是源于靺鞨的民族，不仅有曾一度在高句丽处于韩民族影响之下的历史，而且在当时高丽的视角下，他们是难以找到文化象征意义的野蛮人。女真代表的称谓是"酋长"，在高丽看来，他们是向自己[来朝](https://db.history.go.kr/goryeo/level.do?levelId=kr_004r_0100_0060_0040&types=r)、[归附](https://db.history.go.kr/id/kr_009r_0020_0020_0040)、[进贡](https://db.history.go.kr/goryeo/level.do?levelId=kr_004r_0050_0010_0010&types=r)的低一等的对象。例如，建立高丽的王建毫不避讳地对女真使用了"北蕃之人面兽心"([人面兽心](https://db.history.go.kr/goryeo/level.do?levelId=kr_002r_0010_0040_0020&types=r))这样的蔑称。对于这种等级的认识，女真自身也相差不大，他们承认高丽是与高句丽、渤海相关的上层文明，并运用将自己表述为高丽之蕃的外交修辞。

这种关系持续了约200年。渤海灭亡后，女真虽作为辽的一员被征服，但仍称高丽为"父母之国"，通过边境贸易获得生活必需品，或归化高丽并接受官职，作为处于高丽文明圈保护和控制下的边境存在。高丽也利用这种与女真的不对称关系作为促进边境稳定的手段，以及实现国内海东天下观正当性的思想依据。

## **金朝建立与高丽的动摇**

12世纪初高丽仁宗的统治是高丽史上需要密切关注的历史时期。他在位期间，国内外权力以多种形式出现对立，政治地形随之快速变化。除了宋朝的册封提议和假道请求、黄州瞻的称制建元请求等小事件外，当时高丽内外发生的主要局势变化按顺序整理如下：

| 年份 | 主要事件 |
| :--- | :--- |
| 1109年 | 高丽征伐女真以失败告终。 |
| 1115年 | 女真建立金朝。 |
| 1116年 | 高丽停止使用辽年号。 |
| 1122年 | 高丽仁宗即位。 |
| 1125年 | 辽被北宋和金灭亡。 |
| 1126年 | 高丽向金称臣。 |
| 1126年 | 高丽发生李资谦之乱。 |
| 1127年 | 北宋被金灭亡。 |
| 1135年 | 高丽发生妙清之乱。 |
| 1142年 | 高丽开始使用金年号。 |

考虑到他的统治处于高丽鼎盛时期的延长线上，对金事大意味着向长期以来归附于己的蛮族称臣，这需要巨大的认知转变，是一个艰难的决定。高丽内部也分化为两派：主张我们应该宣布帝国并准备征伐金朝的西京门阀贵族，和主张目前国力不济且金朝强大故应向金称臣的开京门阀贵族。

撇开哪种立场在政治上正确不谈，1126年掌握实权的李资谦决定[向金擅自称臣](https://db.history.go.kr/id/kr_015r_0060_0030_0030)，仁宗接受后[向金皇帝发送了表文](https://db.history.go.kr/goryeo/level.do?levelId=kr_015r_0060_0040_0020&types=r)。虽然李资谦很快被驱逐，但外交路线并未修正。向曾视作野蛮人而忽视的女真事大，需要长达15年的时间，但最终在1142年高丽王接受金朝册封，高丽正式[开始使用金年号](https://db.history.go.kr/id/kr_017r_0040_0070_0010)。

这种突然的政治潮流威胁了高丽的海东天下观，从而引发了政治冲突，进而发展为西京迁都运动，并最终导致了[妙清之乱](https://db.history.go.kr/goryeo/level.do?levelId=kr_016r_0070_0010_0020&types=r)这一极端形式的反抗。不过，妙清之乱并非单纯维护传统和自主性的运动，要理解其意义，需要先审视复杂的政治地形。1127年，在流放政治巨擘拓俊京的过程中，其空缺由以郑知常为核心的西京政治势力填补，仁宗也出于牵制以金富轼为代表的传统开京门阀贵族的意图而优待他们。

在这种情况下，西京派提出了西京迁都和称制建元等打破现状的激进积极进取路线，与坚持维持现状、追求实际利益的现实主义立场的开京派形成对立。这不仅仅是政治路线的差异——西京派以风水地理和佛教神秘主义为旗帜，开京派则以理性主义儒教思想为依托，局势甚至激化为两股政治势力的利益斗争、国风派与汉学派的理念冲突、佛教与儒教的对立。

这种紧张局势以未经策划的西京派名义的叛乱[被镇压](https://db.history.go.kr/goryeo/level.do?levelId=kr_016r_0080_0020_0030&types=r)而告终。结果，高丽的主导权归于开京政治势力，权力平衡被打破，西京的地位也被降格。我们今天所熟知的现实主义事大主义、儒教保守主义、三韩继承意识等思想，正是在此时因竞争对手的消亡而得以巩固，或至少奠定了基石。

## **对两种思想的个人评价**

12世纪高丽所面临的局面，从国家层面来看是一出巨大的荒谬：既有人类渴望守护作为继承高句丽光荣的自主国家的尊严和自豪感，又有曾被视作蛮族的女真族建立的强大金朝在嘲笑这种信念，还有由此产生的内部政治冲突。借用加缪的视角，当时高丽主流政治势力——西京派和开京派截然不同的应对方式，似乎可以理解为：

西京派的主张最终归结为征伐金朝，因此也有余地被视为对世界沉默的否定或反抗，但他们为说服大众和王所使用的正式论据是基于佛教和风水地理等神秘主义的希望，他们的运动没有这种信仰就不可能成立，这在哲学意义上更接近哲学性自杀。特别是迁都西京建造宫殿就能解决所有问题的信念，虽然在情感上可能令人痛快，但并非是理性地认识到荒谬并与之斗争，而是试图用另一种非理性来掩盖荒谬。

相反，开京派的主张不依赖于征伐金朝的情感诉求或盲目信仰，而是接受屈辱的现实作为国家存续的生活条件，追求缓解外交紧张关系等实际利益。这是不否定或逃避荒谬，而是将其拥抱为人类条件的态度，是与荒谬直面、走自己的路，因此更接近反抗的人的形象。虽然这无疑是维护既得利益的手段而非哲学反思，但考虑到500年后丙子胡乱中出现类似困境时，主战派的强硬倾向成为主流所导致的结果，那么即使将开京派的要旨理解为试图抓住人类对抗荒谬的唯一武器——理性的一部分，也不会有太大的违和感。

就个人而言，历史没有如果，所以关于哪种主张正确，我想保持缄默。只是由于这一系列事件发生后不久，1170年毅宗时期发生了武臣政变，如果国家运营哲学得以正常维持，高丽会对金朝采取何种外交路线、内部会有怎样的讨论，这些可能性都已消失，这令人感到遗憾。

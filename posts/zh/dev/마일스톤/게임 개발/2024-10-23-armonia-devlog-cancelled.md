## **发生了什么**

![gameplay](/2024-10-23-armonia-devlog-cancelled/gameplay.webp)
*最新版本的游戏玩法*

如果能早点整理就好了，但直到有了确信才现在写下来。行尽地是出于尝试新的编程模式和一点点新鲜表现手法的贪念而开始的项目，我曾投入到写了[三次开发记录](https://hyngng.github.io/tags/armonia/)的程度，也有一些开发成果，但最终开发还是中止了。

## **坦诚写下的反省书**

最后开发时我所感受到的是义务感和枯燥。虽然是我自己开始的事情，但到了最后，敲键盘这件事似乎变得有些吃力。

为什么会发生这样的事呢？实际上，比起能力不足，不想继续做下去的心情才是第一个原因。毕竟，这原本是练习用的。在达到一定目标后权衡机会成本时，我开始怀疑现在好好收尾这件事是否是最好的选择，而且没有找到答案。

第二个拖累我的是错误的方向设定和长期计划的缺失。因为没有真心实意地认真对待，所以没有截止日期或具体的达成目标，面对问题情况时仍然频繁地即兴解决。遇到问题时，也很少投入必要的努力去定义情况、寻求最佳解决方案等。

第三，没有具体的开发流程或机制。相比于编程，在制作图像和动画资源的过程中这种问题更为频繁。最大的目标是呈现出像电影场景一样自然的画面，但为绘图所需的每一项工作都比想象中需要更多的努力，说实话我感到有些不知所措。

结果，积极性下降了，与其以并非真正热爱的执着拖延下去，不如将对明智解决问题的必要性及改善工作低效的思考搁置一旁，就此结束短暂的开发日程，我认为这样更好。

- 基本说明
	- [X] 名称：行尽地（英文：waybound）
	- [X] 类型：横版卷轴冒险
	- [X] 形式：2.5D 移动端
- 游戏玩法
	- [X] 玩家在城市外围环境中成为构成环境的人、~~狗、猫、蚂蚁~~等生物，执行该生物所具有的互动。例如，人从自动售货机取出饮料饮用，~~狗闻街边长椅的气味。~~
	- [x] 即使玩家不特意操控生物，生物之间也会相互互动，构成城市外围的氛围，每种生物在指定范围内拥有外观上的个性。
- 主要特点
	- [x] 对象间~~多种~~互动
	- [x] 手绘图像与逐帧动画
	- [ ] ~~雨、雪等随天气变化的体验~~

针对人和鸽子实现了互动，但标记删除线的狗或猫等未能实现。已制作的互动谈不上多样。天气也想通过粒子系统实现，但未能实现。

不过，无论如何，尝试了既不是 2D 也不是 3D 的 2.5D 并达到了产出成果的阶段、同时部分使用了手绘图和传统逐帧动画等，我认为这些算是小小的收获。

## **下次要做得更好**

无论如何，开发过程并不令人满意，这是一个失败的项目。主要原因是缺乏诚意的解决问题过程以及对改善工作低效的放弃，首先，我觉得最好去看看其他人是如何解决类似问题的。

一开始是想做一个非常棒的作品，但在这里收尾实在令人不甘。说实话，有点不服气。我会回顾帖子中没有写到的细微之处，好好准备，争取下次能坚持完成。

在开发[股票自动交易程序](https://hyngng.github.io/posts/astp-devlog/)时，曾遇到程序无法在64位环境下运行的情况。作为替代方案，查找了搭建32位虚拟环境的方法，大部分推荐使用Anaconda，但比较麻烦。寻找替代方案后发现可以在VS Code中打开32位虚拟环境。按步骤操作后发现方法并不难，简单整理如下。

## **安装虚拟环境**

```sh
python -m venv 文件名

cd Scripts
.\Activate.ps1

deactive
```

通过输入三条命令，在指定路径创建文件即可。虚拟环境可以通过调用 `Scripts/Activate.ps1` 文件来运行，输入 `deactive` 命令可以退出。如果VS Code控制台窗口文件路径前显示 `(venv)`，则表示虚拟环境已正常运行。

## **错误解决**

```sh
C:\Users\UserNameHere\AppData\Local\Programs\Python\Python311-32\python.exe -m venv venv32bit
```

如果按上述操作仍无法打开32位虚拟环境，可以安装[32位Python](https://www.python.org/downlostart_with_ads/windows/)后，在控制台中直接调用32位的 `python.exe` 即可解决。
